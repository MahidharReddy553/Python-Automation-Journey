# Week 10 - MySQL Practice

## 📌 Overview
This week is dedicated to practicing **MySQL database concepts** and strengthening query-writing skills.  
The focus is on understanding how to design tables, apply constraints, and use joins and aggregate functions effectively.  
These exercises build the foundation for integrating MySQL with Python automation projects.

## 🛠️ Topics Covered
- **Database & Table Creation**
  - Creating databases and tables
  - Applying primary keys and foreign keys
- **SQL Queries**
  - Basic operations: `SELECT`, `INSERT`, `UPDATE`, `DELETE`
  - Filtering with `WHERE`, `LIKE`, `IN`, `BETWEEN`
- **Joins**
  - Inner Join, Left Join, Right Join, Cross Join
- **Aggregate Functions**
  - `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
  - Grouping with `GROUP BY` and filtering with `HAVING`
- **Constraints**
  - `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`

## 📖 Important Points
- Joins are essential for combining data across multiple tables.
- Aggregate functions simplify reporting and analytics tasks.
- Constraints enforce **data integrity** and prevent invalid entries.
- Practicing queries improves confidence in handling **real-world databases**.
- A strong understanding of SQL is crucial before integrating with **Python automation**.
